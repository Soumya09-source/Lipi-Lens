North Karnataka Kannada dataset — version 0.1

Source: Maadi Madidavaru (ಮಾಡಿ ಮಡಿದವರು), Basavaraj Kattimani.
Abridged by Dr. Srinivasa Havanur. User-supplied 80-page PDF.

Files:
- vocabulary/regional_words.json
- sentences/regional_sentences.json
- paragraphs/regional_paragraphs.json
- metadata/dataset_info.json

Caution:
This is a first-pass OCR-derived dataset. Dialect candidates are unverified.
The novel is set in/around the Belagavi region and contains colloquial dialogue,
but narration and all sentences should not automatically be treated as dialect.
Paragraph records are contiguous excerpts, not guaranteed original paragraph boundaries.
